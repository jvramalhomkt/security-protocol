# cybersecurity-audit

Skill de auditoria e hardening de segurança para servidores, apps web, APIs, Docker, bancos de dados, CI/CD e domínios.

## Conteúdo
- `SKILL.md`
- `references/`

## Objetivo
Fornecer um protocolo reutilizável para diagnóstico, relatório, plano de ação, execução aprovada e validação pós-correção.

## Segurança
Este repositório não deve conter credenciais, tokens, IPs privados do cliente, domínios sensíveis, dados de acesso ou segredos operacionais.
